🔎 Aide à la création de votre QR Code

⚙️ Options communes à tous les QR Codes

  • Taux de correction d'erreur :
    • L (7%) : Rendu optimal, QR en bon état
    • M (15%) : Bon compromis
    • Q (25%) : Plus résistant
    • H (30%) : Très résistant pour les surfaces exposées
  • Taille du QR Code : 50x50, 100x100, 150x150, jusqu'à 500x500
  • 💡 Plus la taille est grande, plus la lisibilité sera bonne, surtout à distance ou en impression.

🌐 QR Code URL

Exemple : https://www.monsite.com

⚠️ L’URL doit commencer par http:// ou https:// et ne pas dépasser 50 caractères.

📝 QR Code Texte

Exemple : Bienvenue sur mon site !

💡 Saisissez un message, une phrase ou des informations utiles.

👤 QR Code VCard (Contact)

  • Nom : Jean Dupont
  • Téléphone : +33612345678
  • Email : jean.dupont@email.com

📞 QR Code Numéro de téléphone

Exemple : +33612345678

💡 En scannant, un appel est proposé.

📧 QR Code Email

  • Email : contact@exemple.com
  • Sujet : Demande d'informations
  • Message : contenu de l’email

💬 QR Code SMS

  • Numéro : +33612345678
  • Message : contenu du SMS

📶 QR Code WiFi

  • SSID : nom exact du réseau
  • Mot de passe : laisser vide si réseau ouvert
  • Type de cryptage :
    • WPA : recommandé
    • WEP : ancien
    • Aucun : non sécurisé

📍 QR Code Localisation

Latitude : 48.8566

Longitude : 2.3522

💡 Utilisez Google Maps pour récupérer les coordonnées.

📅 QR Code Événement

  • Titre : Soirée d'anniversaire
  • Lieu : adresse de l’événement
  • Date et Heure : à sélectionner

🖼️ Charger un QR Code existant

Chargez une image au format .png ou .jpg contenant un QR Code à lire.

✅ Conseils généraux

  • Relisez vos informations avant de générer le QR Code.
  • Utilisez un bon contraste : fond clair et QR foncé pour une meilleure lisibilité.
  • Plus la densité des données est élevée, plus le QR doit être grand.

ℹ️ Important :
Le QR Code est généré en temps réel dans votre navigateur à partir des informations que vous saisissez.
Aucune image n’est stockée sur notre serveur. Vous pouvez télécharger ou utiliser directement le QR Code affiché.
